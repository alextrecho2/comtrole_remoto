## 🎯 Objetivo
Explique meu controle conecta pelo bluetooth do carrinho lego para ele andar conforme a programação do contro lados,frente e tras. 

## ✨ Funcionalidades
- Funcionalidade 1 conecta pelo bluetooth
- Funcionalidade 2 conecta pelo bluetooth
- Funcionalidade 3 e o botão de parada de ermergencia

## ️ Tecnologias Utilizadas
- **MIT App Inventor**
- **GitHub**,lego nxt

## 📂 Como testar este aplicativo?
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o https://ai2a.appinventor.mit.edu/?locale=pt#7988402
3. Clique em **Projetos > Importar projeto (.aia) do meu computador**.
4. Selecione o arquivo baixado para visualizar e testar o código!
